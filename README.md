# 🏆 GitHub Achievements Hunter

¡Bienvenido al **GitHub Achievements Hunter**! 🎯

Este repositorio es una herramienta para ayudarte a ti (y a otros) a desbloquear los logros (badges) ocultos y públicos en tu perfil de GitHub. 

## 🏅 Logros que puedes cazar aquí

### ⏱️ Quickdraw
1. Ve a la pestaña de **Issues** en este repositorio.
2. Crea un nuevo Issue (puedes ponerle de título "Test").
3. ¡Ciérralo en menos de 5 minutos! Obtendrás el logro casi de inmediato.

### 👯 Pair Extraordinaire
1. Clona este repositorio.
2. Haz un pequeño cambio en algún archivo (por ejemplo, agrega tu nombre aquí abajo).
3. Haz un commit y en el mensaje incluye lo siguiente (dejando una línea en blanco antes): 

```text
Mensaje de tu commit

Co-authored-by: github-actions[bot] <41898282+github-actions[bot]@users.noreply.github.com>
```
4. Sube el cambio (Push).

### 🧠 Galaxy Brain
1. Ve a "Settings" (Configuración) de tu repositorio en GitHub.
2. Baja a la sección Features y activa **Discussions**.
3. Pídele a un amigo que abra una nueva discusión aquí con una pregunta.
4. Respóndele y pídele que marque tu respuesta como la **Accepted Answer**. ¡Repite esto 2 veces!

### 🌟 Starstruck
¡Este es de popularidad! Si este repositorio te sirvió para ganar tus insignias, compártelo con tus amigos. Al llegar a 16 estrellas (⭐), desbloquearás el logro.
